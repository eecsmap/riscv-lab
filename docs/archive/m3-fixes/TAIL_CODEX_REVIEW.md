# M3 run-b复核（2026-09-16）

结论：退出事务专项通过本轮限定验收；M3尚余AXI时间因果门禁一项阻断，不最终收口。

证据codex-tail-review-DsiBfv。使用sim3归档模拟器，未重编译：正常/withhold/error/delay模式退出0/3/0/0；正常和延迟事件checker退出0，错误响应被checker退出1拒绝。7项既有AXI探针均拒绝，74项源码/ELF/模拟器输入哈希通过。

首轮误用了保留的sim而非sim3旧模拟器，其mode日志不作当前交付结论；current-mode日志才是本轮采纳证据。原日志保留，所有进程均已结束。

## 退出专项认可

实际TAILHIT为seq630、PC0x80000084、地址0x800000c0、数据1，不再命中控制台。延迟模式HOSTDONE busy=1，1887周期后SETTLED（正常5周期）；CPU退出响应8487、退休8489。error精确cause7/epc0x80000084/mtval0x800000c0，原始进程0但最终事件门禁明确拒绝。withhold原始进程3。保留“模拟器退出码不是最终验收结果”的边界。

## AXI唯一剩余阻断：预装未来请求掩盖提前响应

check-axi.py先收集所有AR/AW，再配对R/W，B只比较ID列表排序；cycle虽被读入却不用于约束响应依赖。

独立axi-time-probe.py把全部R时间改为0，checker仍0；把全部B时间改为0也仍0。因此目前不能证明响应时请求已存在，B也未证明对应写数据已完成。旧7探针通过不能覆盖这个缺口。

最小修复应按cycle分组处理真实时间线：R必须有当时已握手AR；B必须有当时已握手AW及对应完整W。W可合法早于AW，须缓存未配对W按顺序关联，不能错误禁止；不同ID响应可乱序，同ID按序。正确处理同周期事件，不依赖打印行顺序。加入提前R、提前B（AW前/WLAST前）、合法W-before-AW及跨ID乱序正向探针，检查缺字段/末尾遗留。

本轮不要求重构CPU、重做已认可退出专项或扩展ISA。修checker并重放既有8项日志即可；若改变RTL再按影响回归。待本项通过后再裁定M3整体完成，不上板。
