# Results index

Generated tables live beside this file. Nothing here is hand-written data.

| file | what | generated by |
| --- | --- | --- |
| `comparisons.csv` | every measured ROI from every run, flattened | `benchmarks/tools/gen_comparisons.py` |

Regenerate and verify with:

```bash
make bench-metrics      # each run's metrics.json, from its immutable raw/ records
make bench-check        # regenerates comparisons.csv into a temp file and diffs the committed one
```

## Reading the table

* `cpi_median`, `cpi_min`, `cpi_max` over **successful** samples only; `samples_failed` counts the rest.
* `derived_ips_median` is `configured_hz / CPI` and is marked `model-derived`. It is **not** measured
  throughput. See `benchmarks/metrics.md` §4.
* an empty metric cell means **null** — no successful samples — and never zero.
* board and simulator rows are both present and must not be divided by one another; the simulator models
  no PS or DDR path. `gen_comparisons.py:ratio()` refuses such comparisons.
